# Numerical verification

This package evaluates the detector experiment directly in finite dimensions. It builds the POVM effects, applies them to joint input–memory density matrices by partial trace, and computes symmetric logarithmic derivative (SLD) Fisher information and Umegaki relative entropy from matrix eigendecompositions. The exact formulas in the science pages are comparison targets, not replacements for those matrix calculations.

## Run

Use Python 3.11 or newer and the pinned NumPy dependency. From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r verification/requirements.txt
python verification/run_all.py
```

The script prints one JSON object and exits successfully only if every check passes. An assertion failure exits with a nonzero status and names the failed quantity. To save a new result separately from the committed reference:

```bash
python verification/run_all.py --output /tmp/quantum_detector_memory_results.json
```

The deterministic random seed is `20261030`. The script imports only NumPy and the Python standard library. It needs no network access, external data, plotting package, or quantum-computing framework after dependency installation.

## What is checked

| Check | Coverage and scientific purpose |
|---|---|
| Physical output construction | Direct contractions of every nonidentity Pauli effect with the joint density matrix. A separate Kronecker-product multiplication and partial trace checks the contraction convention, including complex Pauli entries. |
| SLD and relative-entropy evaluation | Spectral calculations on unnormalized output blocks, compared with an explicitly assembled full block-diagonal output matrix in a small case. Block-probability derivatives are included. |
| Exact memory frontiers | Every integer $`1\leq r\leq d`$ for $`d=2,4,8`$, at $`\theta=0,0.2,-0.6,0.9`$. Both contiguous and permuted computational subsets are used, including non-power-of-two dimensions and nonconsecutive subsets. |
| Attaining readout | Explicit eigendecomposition and measurement of each transposed Pauli compression. The resulting probabilities must equal the three-outcome erasure-coin distribution. |
| Random input bounds | Random pure inputs, full mixed inputs, and states with a rank-deficient memory marginal. Direct SLD and Umegaki quantities are compared with their one-use upper bounds. |
| Moving away from zero | The computed information of each random input must obey its stronger input-specific bound $`F_\rho(\theta)\leq F_\rho(0)/(1-\theta^2)`$. |
| Transpose signs | Explicit odd- and even-$`Y`$ cases. The correct retained observable reproduces the visibility, while an uncorrected odd-$`Y`$ readout reverses its sign. |
| Adaptive increment identity | Parameter-dependent incoming states generated by actual preceding detector calls, followed by parameter-independent processing. The direct output derivative must reproduce the zero-visibility cancellation identity and satisfy the increment bound. |
| Complete adaptive experiments | Six two-query protocols at $`d=2,4`$, including $`r=3`$. First-query outcomes control fixed subsequent unitaries; all histories and their probabilities are retained. The final quantum Fisher information must not exceed $`2c_r`$. |
| Finite-sample decision caveat | Direct qubit total-variation distances reproduce a case in which the Fisher-optimal erasure experiment is not optimal for a particular one-call test. |

The physical incoming families cover two mechanisms. One preceding query is measured and used to choose a prepared joint state, then its classical result is discarded. In the other, a recorded outcome of an entangled preceding query leaves a parameter-dependent retained state, which is combined with a fresh probe by a fixed unitary. The latter family's derivative is also checked by a central finite difference. Conditioning is used only to check the local increment identity; the separate complete two-query calculations retain every branch and its probability.

The SLD implementation keeps support–kernel off-diagonal tangent components. A singular-state diagnostic checks this convention explicitly. The relative-entropy implementation checks that the numerator lies in the reference support before taking logarithms; it does not silently assign a finite value when that support condition fails.

## Numerical tolerances

The defaults are declared at the top of `run_all.py` and included in every result:

| Quantity | Tolerance |
|---|---|
| Scalar or entrywise comparison | Absolute $`3\times10^{-9}`$ plus relative $`3\times10^{-9}`$ |
| Positivity, Hermiticity, and support diagnostics | $`2\times10^{-11}`$ |
| Eigenvalue cutoff in spectral calculations | $`10^{-12}`$ |
| Central finite-difference step | $`10^{-5}`$ |
| Finite-difference derivative comparison | Absolute $`3\times10^{-8}`$ |

An `error` field reports the largest absolute discrepancy observed in that category. An `excess` field reports the largest computed value minus its upper bound; a negative value means that all checked cases were below that bound. Tiny positive excesses and tiny negative numerical relative entropies can arise from floating-point arithmetic and are subject to the stated tolerances.

The eigenvalue cutoff is only a numerical convention. The analytical results use exact supports and the Moore–Penrose inverse. The tested interior visibilities keep the attaining outputs away from the singular detector endpoints; this package does not extrapolate numerical conclusions to $`\theta=\pm1`$.

## Saved reference result

The committed [reference result](reference_results.json) was generated with Python `3.12.14` and NumPy `2.3.5` using:

```bash
python verification/run_all.py --output verification/reference_results.json
```

It reports a pass. The largest observed discrepancy in the exact SLD frontier was approximately $`7.11\times10^{-15}`$; the exact relative-entropy frontier differed by at most $`1.39\times10^{-15}`$. The explicitly measured erasure distribution differed by at most $`5.89\times10^{-15}`$. The adaptive cancellation discrepancy was at most $`1.67\times10^{-16}`$, and the physical-family finite-difference derivative discrepancy was at most $`2.68\times10^{-12}`$.

Different hardware or linear-algebra builds may change the final floating-point digits. Reproduction means that the checks pass within the declared tolerances, not that the JSON bytes match exactly. The saved JSON records the complete quantitative outcome and the semantic coverage counts.

## What these checks do not establish

The checks do not prove an arbitrary dimension, an asymptotic sample-complexity law, or a universal adaptive statement. They also do not certify exact optimality for every finite-sample decision loss. Those distinctions are part of the scientific result, rather than exceptions to the verification.

The analytical foundations are:

- [Fisher information](../science/fisher_information.md): the exact one-use frontier and the adaptive zero-visibility bound.
- [Attaining protocol](../science/attaining_protocol.md): arbitrary integer memory dimension, the transposed readout, and the exact erasure experiment.
- [Relative entropy](../science/relative_entropy.md): the exact comparison with zero visibility.
- [Adaptive calibration](../science/adaptive_calibration.md): global minimax estimation and testing consequences.
- [Model](../science/model.md): retained-memory, delayed-label, and complete-record assumptions.

The verifier concerns these mathematical detector models. It does not benchmark a physical device's gate noise, timing, detector imperfections beyond the specified visibility, or energetic costs.
